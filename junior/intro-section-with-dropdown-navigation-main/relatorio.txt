#Desafio: Frontend Mentor - intro-section-with-dropdown-navigation-main

Nível: Junior
Recursos e avaliação: implementação usando claude code no terminal do codespaces. Comentário: Fundação realizada de modo manual com npm init -y na pasta do desafio e instalação do Sass depencia do desenvolvedor, criação das estruturas de parciais para o sass e adição de scripts no package.json para o sass.
Fluxo da implementação: claude.md foi criado manualmente utilizando instruções já existente, porém uma parte dele deve ser criado pelo assistente após leitura do desafio. Prompt 1- pedido ao assistente para apresentar a Estrutura e pontos de atenção especificos do desafio; 


  para gerar o documento design-system.md, apesar de ter gerado o documento o MCP do figma apresentou limite de requisição, logo foi necessário substituir pelas imagens dos layout exportados do figma referente aos 3 layouts; 1-prompt de levantamento das informações (Blocos BEM, tokens de cores, espaços, radius, tipografia) que o assistente consegue identificar onde ele retornou o que muda entre os breakpoints, ambiguidades a serem respondidas; 2-prompt as ambiguidades foram respondidas e o HTML foi implementado e a sessão foi encerrada; 3-prompt em nova sessão, foi pedido o assistente para ler o design-system.md e as imagens dos layout para obter contexto e relatar ambiguidades ele retorna ambiguidades similares ao prompt 2, não presistindo as respostas anteriores. Solução para o problema foi retornar a sessão encerrada usando o comando "/resume" do claude code, selecionar a sessão do prompt 2, nesta sessão foi perguntado se há alguma ambiguidade ainda a ser respondida para implementar o CSS, as quais foram retornadas pelo asssistente apenas ambiguidades novas, as anteriores já haviam sido respondidas, sendo implementado o CSS.
